# Development rules

1. Read `course_artifacts/directive.md`, `deblock/spec.md`, and relevant tests before changing
   behaviour.
2. Preserve authorship, voluntary stopping, and privacy by default.
3. Do not add clinical claims, inferred psychological traits, silent telemetry,
   authentication, payments, social sharing, or AI-generated writing without an
   explicit owner decision.
4. Tests must state expected behaviour; do not weaken existing acceptance tests
   to make a change pass.
5. Record the verification command and actual output with a completed change.
