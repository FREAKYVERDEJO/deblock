# Course artifacts

This folder keeps the project artifacts created for the DS403 course in one
place. They document decisions and research plans; they do not make claims that
uncollected research or user testing has already happened.

- [directive.md](directive.md): product invariants controlled by the project owner.
- [niche_brief.md](niche_brief.md): candidate niches and the selected early segment.
- [fact_ledger.md](fact_ledger.md): facts, decisions, and explicit unknowns.
- [competitor_scan.md](competitor_scan.md): positioning notes and research gaps.
- [deep_research_prompt.md](deep_research_prompt.md): the next research question.
- [personas.yaml](personas.yaml): assumption-based critique personas.
- [wave_1_plan.md](wave_1_plan.md): a planned, not yet executed, usability wave.
- [rules/](rules): development and critique guidance.
